# 赞助二维码图片说明

## 📁 文件位置

请将您的收款二维码图片放置在此目录下：

- **支付宝收款码**: `alipay.png`
- **微信收款码**: `wechat.png`

## 📐 图片要求

- **格式**: PNG 格式（推荐）或 JPG 格式
- **尺寸**: 建议 400x400 像素或更大（程序会自动缩放到 180x180 显示）
- **内容**: 清晰的二维码图片，确保可以被扫描

## 🎨 图片准备建议

1. 使用支付宝/微信的"收款码"功能生成二维码
2. 截图或保存二维码图片
3. 裁剪图片，只保留二维码部分（可以包含少量边距）
4. 调整图片大小为正方形（如 400x400、500x500 等）
5. 保存为 PNG 格式以获得最佳显示效果

## 📝 文件命名

- 支付宝: `alipay.png`
- 微信: `wechat.png`

**注意**: 文件名必须完全匹配，区分大小写！

## 🔄 更新步骤

1. 将二维码图片复制到此目录
2. 确保文件名正确
3. 重新编译项目（如果已编译过）
4. 运行程序，点击"关于" → "💝 赞助支持"查看效果

## ⚠️ 占位符说明

如果没有添加二维码图片，程序会显示占位符提示文字，告知用户需要添加图片。这不会影响程序的正常运行。

## 💡 提示

- 二维码图片会被嵌入到程序资源中，编译后无需单独携带图片文件
- 如果需要更新二维码，修改图片后需要重新编译程序
- 建议定期检查二维码是否有效，避免过期失效
